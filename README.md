# Password-maker

## Overview

**Password Maker** is a simple and customizable tool to generate strong, secure passwords based on your specified criteria. The app allows users to choose the length of the password, and whether to include uppercase letters, lowercase letters, numbers, and symbols.

This project was built using **HTML**, **CSS**, and **JavaScript** to help users create secure passwords for various online accounts and services.

## Features

- **Password Length**: You can set a password length between 4 to 20 characters.
- **Character Types**: Choose from four different character types:
  - Uppercase Letters
  - Lowercase Letters
  - Numbers
  - Symbols
- **Clipboard Copy**: Easily copy the generated password to your clipboard with a click of a button.
- **Responsive Design**: The tool works well on both desktop and mobile devices.

### Prerequisites

- A web browser (e.g., Chrome, Firefox, etc.)
- A text editor (e.g., Visual Studio Code, Sublime Text)

### Installation

1. **Clone the repository**:
   ```bash

2. **Navigate to the project folder:
   ```bash

3. **Open the index.html file in your web browser: Simply double-click the index.html file or open it via your text editor and launch it in the browser.No server setup is required. This project is fully client-side and works out of the box.
